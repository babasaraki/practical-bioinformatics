Prepared against the requirements CRC typically sets for a single-authored
technical textbook. Items marked **author** need a decision or a file that only the
author can supply.

## Reference style, checked against the publisher's own guidance

CRC Press/Taylor & Francis document the *Chicago Manual of Style* as their house
reference style, while stating that logical variations are acceptable provided a
consistent style is maintained within any one work. Their current books guidance goes
further: confirm the expected style with the commissioning editor, and if none is
specified, any suitable style may be used so long as it is applied consistently.

What this book now does, and why:

- **Chicago author-date**, set by omitting `csl` in `_quarto.yml`, which selects
  pandoc's built-in default. The first build used APA; both are permissible under the
  rule above, but Chicago is the house default and costs nothing to adopt. `apa.csl`
  stays in the repository, and `csl: apa.csl` switches back in one line.
- **DOIs on every entry that has one.** T&F ask for DOIs wherever available. 148 of the
  154 entries carry a registered DOI. The six without are `maaten2008` (t-SNE) and
  `pedregosa2011` (scikit-learn), both in the *Journal of Machine Learning Research*,
  which assigns none; `rcoreteam`, the R language manual, and `fastqc`, the FastQC
  documentation, neither of which is a registered publication; `dayhoff1978`, a chapter
  in the *Atlas of Protein Sequence and Structure* that predates DOI registration; and
  `csardi2006`, the igraph paper in *InterJournal, Complex Systems*. All six are marked
  MANUAL in `references.bib`, meaning they were entered by hand rather than resolved
  from a registrar, and `scripts/check_manuscript.py` reports the count so it cannot
  drift.
- **Figures and tables numbered per chapter, starting at 1**, which is what CRC
  requires; Figure 4.1 is the first figure of Chapter 4. Every numbered float has an
  in-text call-out, also required.
- **Empty consortium name slots removed.** Crossref returns consortium papers with the
  group author as an empty name, which BibTeX renders as a stray ` and ` and which
  prints as "Aleksander, Suzi A and, James Balhoff". Ten entries were affected. The
  cleaner is now part of `scripts/normalise_bibliography.py`, so re-resolving the
  bibliography cannot reintroduce it.

**One decision remains, and it belongs to the commissioning editor.** T&F guidance asks
for a reference list at the end of each chapter, so chapters can be read in isolation,
and advises against a single list at the back of the book "unless appropriate to your
discipline". This book has one list at the back. For a single-authored textbook read
continuously that is both conventional and defensible, and the guidance is aimed
principally at edited collections. If the editor wants per-chapter lists, Quarto has no
built-in mechanism for it and the `multibib` filter extension would be needed; it is a
configuration change, not a rewrite, but it should be settled before copy-editing
rather than after.

## Foreword

`front-matter/foreword.qmd` is in place as the first item of the front matter, holding
a note that marks the page reserved and an attribution block, commented out, in the
form the writer's name, position and affiliation should take. Replace the note with the
text; or delete the file from the chapter list in `_quarto.yml` if no foreword is
commissioned. Nothing else in the book depends on it.

A foreword is 600-1,200 words and is not a summary or an endorsement: it is an argument
for why the book matters, made by someone whose standing lets them make it. Send the
full manuscript, the table of contents and a deadline, and say plainly that declining
is fine. Allow six to eight weeks.
