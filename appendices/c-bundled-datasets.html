Appendix C — Bundled datasets

Every example in this book runs on the files listed here. They are downloaded from public archives by scripts/fetch_data.py and verified against data/MANIFEST.tsv, which records the exact size and SHA-256 checksum of each file. Nothing in the book depends on data that is not in this list.

python scripts/fetch_data.py          # fetch everything (~12 MB)
python scripts/fetch_data.py --check  # verify against the manifest

Reach these files from chapter code with the book_data() helper rather than a literal path, so that code works from any chapter directory:

from pybfx import book_data
book_data("proteins", "globins.fasta")
Licensing

Each file remains under the licence of the archive it came from. The sequence, structure and variant records are public-domain or openly licensed research data from NCBI, UniProt, RCSB PDB, the AlphaFold Protein Structure Database and STRING. The expression counts come from a Bioconductor data package distributed under the Artistic-2.0 licence. The simulated read files are generated by this book’s own script and carry the same licence as the book’s code.

The read files are simulated, and the book says so

reads/mgen_sim_R1.fastq.gz and its mate are not real sequencing output. They are generated from the bundled Mycoplasmoides genitalium reference by scripts/fetch_data.py with a fixed random seed, using a position-dependent quality decay and matching base-call errors. They behave like real reads for the purposes of the exercises — and because their true origin on the genome is encoded in each read name, you can check your own alignments against the truth, which real data never lets you do. Conclusions about sequencing chemistry should not be drawn from them.
